# Defining Frontmatter in Obsidian

Hugo requires some key-value pairs in a YAML-Style frontmatter.\
To do that do the following

Directly *under* the obsidian page name (first line in the file) type in a new line three dashes: "---"

Obsidian then automatically opens a key value table where you can (very intuitive) set attributes like **title** or **draft** .
