# What is a Project?

# Components of a Project

## Project Description

A Obsidian/Hugo markdown file describing the project, design considerations and "make" and referencing all connected materials as:

* youtube videos
* 3D models on thingiverse
* code on github
*

## Properties of the Markdown

The markdown file describing the project is the "root" or "master" which gives a written description of the project/product along with images, drawings etc.\
Here all information is linked and can be found.\
The markdown should contain one or more the following tags\
\#outdoor for outdoor activities - adventures\
\#bikepacking for bikepacking gear or other product presentations, also to specify which kind of #outdoor activity is shown\
\#3D\_printing for 3D models\
\#jazz\_piano for music related\
\#software for software projects\
\#development for outdoor gear creation\
\#hugo\_site for projects and tasks related to the creation of this site\
\#thinkstuff when musing about things not falling in any of the mentioned categories ...

## Youtube Video

One or more youtube videos to present the project/product
